# Changelog

## Unreleased

- New InputBridge app icon on Windows (exe, installer, window, tray) and macOS (app icon, menu bar).
- Redesigned Windows controller window: sidebar navigation, card layout, toggle switches and an update banner.
- Redesigned macOS menu bar panel and settings window (sidebar + grouped forms).
- When an update is ready, the tray icon (Windows) and menu bar icon (macOS) show an orange "!" badge; Windows also badges the taskbar button.

- Windows and macOS apps check GitHub Releases for new versions, download the installer in the background, verify its SHA-256 digest and install it on request (or automatically when enabled).
- Windows installer restarts InputBridge after silent (in-app) updates and no longer duplicates firewall rules on reinstall.

- macOS Z407 discovery scans in parallel with reconnect, keeps the control session after a successful handshake, and no longer blocks monitor switching if the speaker is missing.
- Optional Windows USB camera share publishes 1080p JPEG over the paired local API; a signed macOS Camera Extension appears as InputBridge Camera.

## 0.2.0

- GitHub release workflow and release documentation added.
- Windows controller source hardened for local/private network requests.
- Windows controller serializes profile changes to avoid overlapping monitor commands.
- macOS build moved to a real Xcode application project generated by XcodeGen.
- macOS discovery keeps controller identity stable while its IP changes.
- G915 monitor uses IOBluetooth first and preserves the proven system-profiler fallback.
- Generic setup documentation now avoids any user-specific IP, token or monitor name.
